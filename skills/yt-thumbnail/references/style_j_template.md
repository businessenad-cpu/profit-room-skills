# Style J — Grid Paper (Light Editorial)

## Description
Clean, editorial, light format. Off-white or white grid paper background — the subtle grid lines are visible across the entire frame. Person centered or slightly off-center, clean cutout feel. Bold text placed directly on the background with a heavy drop shadow OR large standalone text beside the person. No dark mood, no bokeh. High contrast, flat lighting, graphic design energy.

Reference formats: a normal-vs-cringe comparison, or one big monthly-earnings number on a clean background.

## Placeholder Guide

### [INSERT STAT / TEXT]
- Large numbers work extremely well: "$8,947", "0 → 14K", "$2,500/mo"
- Short punchy statements: "NO AUDIENCE.", "NO CLIENTS."
- Comparison labels: "NORMAL / CRINGE", "EVERYONE ELSE / YOU", "BEFORE / AFTER"

### Accent colors
- **Red** — primary accent on light backgrounds. Pops harder than orange against grid paper. Use for the power word, underline, or contrast label.
- **Black** — default for all large text on this light background
- **Do NOT use orange or yellow** — orange is weak on light backgrounds; yellow disappears entirely. Save yellow for dark background styles (G).

## When to Use
- Outcome/proof content where the number IS the hook
- Comparison or contrast content (before/after, this vs that)
- Educational framework content that benefits from a clean, credible look
- When all 3 thumbnails in a set skew dark — use this for visual diversity
- Pairs well with: Number Drop, The Formula, Stop/Start title formats

## Logo Handling
Logos render well against the light background. Pass `--logos` as normal. They appear as clean flat icons, not glowing.
