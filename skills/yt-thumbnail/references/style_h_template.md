# Style H — Hybrid (Photorealistic + 3D Totem)

## Description
A photorealistic shot: you hold a 3D modular totem against a dark cinematic bokeh background. This is the personal version of Style A — instead of a stylized 3D character, the real person holds the framework artifact. Combines the emotional warmth of a real face with the visual clarity of a structured totem. Best for frameworks, levels, systems — same use cases as A but with more human gravitas.

Contrast with Style A: A uses a fully 3D character on a bright eggshell background. H uses the photorealistic reference photo on a dark cinematic background. Same totem logic, opposite mood.

## Block Label Strategy (same as Style A — pick one)

| Strategy | When to use | Example |
|----------|-------------|---------|
| **Numbers + logos** | The levels ARE the video's reveal — naming them spoils the click | Blocks labeled "1" "2" "3" "4", each with a tool icon |
| **Numbers + top `?`** | Strong intrigue — bottom levels hint, top level is the reward | "1" / "2" / "3" / "?" — the `?` block glows brighter |
| **Logo icons only** | Tools are the story, not the framework | No text on blocks, just Claude / LinkedIn / Obsidian icons stacked |
| **Vague labels** | Framework is known but depth is the reveal | BASIC / SYSTEM / POWER / SECRET |
| **Named labels** | The levels are NOT the reveal (e.g. a known public framework) | HAIKU / SONNET / OPUS — only when naming adds clarity, not curiosity |

**Default to numbers + logos or `?` on the top block. Only use named labels if the video title already names the levels.**

## When to Use
- Framework / levels / system videos (same signals as Style A)
- When A feels too "cartoony" for the topic — H has more gravitas
- When the video is personal ("my system", "how I use X") — the real face adds trust
- Pairs with: Number Drop, Stop/Start, Kill the Subscription copy formats

## Key Rules
- The totem must look physically held — not floating or composited poorly. The hands must wrap around it.
- Dark background is non-negotiable — the totem glow needs darkness to read
- Never use this style with a bright/light background — use Style A for that
- The block count should match the video's framework count (3 models = 3 blocks, 4 levels = 4 blocks)
