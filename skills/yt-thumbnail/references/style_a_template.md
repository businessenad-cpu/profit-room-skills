### Block Label Strategy (pick one — do NOT default to naming the levels)

| Strategy | When to use | Example |
|----------|-------------|---------|
| **Numbers + logos** | The levels ARE the video's reveal — naming them spoils the click | Blocks labeled "1" "2" "3" "4", each with a tool icon. Viewer sees progression, wonders what each level means. |
| **Numbers + top `?`** | Strong intrigue — bottom levels hint, top level is the reward | "1" / "2" / "3" / "?" — the `?` block glows brighter than the rest |
| **Logo icons only** | Tools are the story, not the framework | No text on blocks, just Claude / LinkedIn / Obsidian icons stacked |
| **Vague labels** | Framework is known but depth is the reveal | BASIC / SYSTEM / POWER / SECRET — hints at hierarchy without spoiling |
| **Named labels** | The levels are NOT the reveal (e.g. a known public framework) | CHAT / PROJECTS / SKILLS / VAULT — only use when naming them adds clarity, not curiosity |

**Default to numbers + logos or `?` on the top block. Only use named labels if the video title already names the levels.**
